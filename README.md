# Applied Mathematics Behind Machine Learning

This repository demonstrates how machine learning is built on three core mathematical concepts:

- Linear Algebra → Data representation  
- Probability & Statistics → Predictions  
- Optimization → Model training  

## 📓 Notebook

The notebook shows a simple implementation using a real dataset:
- Data representation using matrices  
- Probability-based prediction using logistic regression  
- Model training and evaluation
